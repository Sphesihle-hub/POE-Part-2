Project Overview
A responsive, SEO-optimised website for Kwa-Mzilikazi, a home-style eatery at 43 Eloff
Street, Johannesburg CBD, serving home-cooked meals, meat bones and refreshments for
dine-in or takeaway.

Website Goals and Objectives
- Increase awareness of Kwa-Mzilikazi among CBD workers and visitors
- Allow customers to view the menu, prices and opening hours online
- Generate enquiries for takeaway, catering and bulk meat bone orders

Key Features and Functionality
- Homepage with hero image and call to action
- About Us page with business history, mission and vision
- Menu page listing dishes, meat bones and refreshments
- Enquiry page with a form for takeaway/catering requests
- Contact page with address, trading hours, embedded map and contact form

Timeline and Milestones
- Part 1: Planning, research, HTML structure (current)
- Part 2: CSS styling, responsive layout, branding
- Part 3: JavaScript functionality, SEO optimisation, testing and deployment

Part 1 Details
Part 1 covers the website project proposal, sitemap, file/folder structure, and the
initial static HTML pages listed above, including semantic HTML5 elements, comments,
and working internal navigation across all five pages. Parts 2 and 3 will extend this
repository with CSS styling and JavaScript functionality respectively.
